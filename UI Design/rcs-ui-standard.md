# RCS 厂内调度 · UI 通用标准

本标准以 Soybean 壳层骨架为底座，再按 NXP RCS 两版登录稿（深色 `0.png` / 浅色 `1.png`）改成**工厂内网控制台**语言。后续页面与数据统一放在 `C:\RCS Design\UI Design`。

一句话：壳是槽位，主题是一份数据；中性炭/冷白负责气质，青绿主色只做识别与主按钮；登录页必须说「厂内调度」，不能说成 SaaS。

---

## 0. 产品定位（先于一切视觉）

| 是 | 不是 |
| --- | --- |
| 半导体厂内 AMHS / RCS 调度控制台 | 公网 SaaS、营销落地页 |
| 内网、授权账号、产线终端可读 | 注册转化、免费试用、品牌口号墙 |
| 设备与路径语境（AMR、STK、OHT…） | 抽象紫雾、通用插画、emoji 图标 |
| 双品牌锁：SIASUN 新松 · DUCO 多可 | 模板 Soybean 豆标与 Vite 紫 |

产品线显示名：`NXP RCS · AMHS CONTROL`  
叙事主标题：`半导体厂内智能搬运调度`（可两行）  
主按钮文案：`登陆 RCS 系统`（登录页唯一实心主按钮）

---

## 1. 两层壳，页面不拥有框架

- **空白壳**：登录、403、404、500。无侧栏、无顶栏、无页签。
- **管理壳**：业务页。槽位固定为侧栏、顶栏、页签、内容、页脚。页面只填内容槽。
- 六种布局只是槽位重排。内容区自滚动；顶栏与页签默认固定；页脚默认不固定、文字靠右。
- 业务页不得自带第二套导航或营销长页结构。

---

## 2. 主题是一份数据

`themeSettings`（或等价配置）是唯一真相。主色、明暗、圆角、布局、密度、页签形态、页脚、水印都从这一份来。

改主色时一起变：色阶、主按钮、选中态、活动页签、文字链、登录标签描边、路径高亮。  
不跟主色走：页面底、卡片、顶栏、侧栏、页脚、正文（写死在明暗两套中性色）。

---

## 3. 一种主色，状态映射固定

- 全站一种主色，落在色阶 500。当前绑定：**青绿 `#15b7a8`**（从登录稿按钮左端实测）。
- 主按钮允许水平渐变：`#15b7a8 → #10a6e6`（右端实测），视为同一主色动作，不算第二强调色。
- 状态：默认/悬停 = 500；按下 = 加深约 12% L（或固定按下色 `#0e8f84`）；选中底 = 主色 12% 透明。
- 悬停不得把文字改浅。禁用是唯一允许降对比的状态。
- 成功 / 警告 / 错误独立：建议 `#52c41a` / `#faad14` / `#f5222d`。信息色可跟随主色。
- **禁止**把主色铺进整页底或每一张内容卡。**禁止** Vite/Soybean 紫 `#646cff` 作为 RCS 主色。

---

## 4. 中性色决定气质

### 浅色（登录左栏 / 业务页）

- 叙事底 / 页面底：`#f0f7f9`（冷薄荷灰，不是奶油米）
- 表单卡 / 内容卡：`#ffffff`
- 正文：`#1f1f1f`；次要：`#7a8a90`；弱文案：`#667178`
- 边框：`#d7e0e4`

### 深色（控制台默认候选）

- 页面底：`#1b1b1b`；卡片：`#1c1c1c`
- 正文：`#f0f0f0`；次要：`#9aa3a8`；边框：`#333333`
- 主色不变

阴影只分层：卡片 `0 8px 28px rgb(0 20 40 / 0.08)`（浅）或 `0 12px 40px rgb(0 0 0 / 0.45)`（深）。登录卡可略强于业务卡。

圆角：控件 8px；内容卡 12px；登录卡 16px；主按钮胶囊（全宽圆角 ≈ 高度一半）。

---

## 5. 字体与图标

- 只用系统无衬线栈（含中文：`"Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`）。
- 大标题加粗；产品线名与设备缩写用等宽或字距略开的小 caps 感。
- 图标：线性（用户、锁、语言、明暗）。禁止 emoji 功能图标。

---

## 6. 管理壳尺寸（业务页）

沿用成熟壳尺寸，便于对接现有 FrontEnd：

| 区域 | 默认 |
| --- | --- |
| 顶栏 | 56px，左右 12px |
| 页签 | 44px |
| 侧栏 | 220 / 收起 64 |
| 页脚 | 48px，右对齐 |
| 内容区 | 内边距 16px，块间距 16px |

顶栏右侧：搜索、全屏、语言、明暗、主题、头像。选中菜单 = 主色字 + 主色 12% 底。

---

## 7. 控件

- 同一视口、同一主动作只有一个实心主按钮。
- 登录主按钮：通栏、大号、胶囊、白字、青绿→天蓝渐变；悬停整体加深，字保持白。
- 次按钮：描边或幽灵。文字链用主色，不另起第三色。
- 输入框：左图标 + 占位符；厂内登录可不显示浮动 label。
- 触控目标 ≥ 44px。

---

## 8. 登录页专规（相对 SaaS 模板的硬差异）

### 版式

- **左右分栏**，约 58% / 42%（窄屏改为上下：上叙事、下表单）。
- 左：产品线名 → 大标题 → 一句话职责 → 洁净室/搬运场景图 → 设备标签条。
- 右：表单卡垂直居中；卡顶双品牌锁 + 语言/明暗；卡内产品线眉题 →「密码登录」→ 说明 → 表单 → 主按钮。

### 背景

- 浅：冷薄荷底 + 极淡方格网格。
- 深：炭黑底 + 极淡网格。
- **禁止**：主色大色斑、居中漂浮营销卡、紫雾渐变。

### 场景图

- 使用真实厂内/AMHS 场景（项目内 `assets/login-hero-cleanroom.png`）。
- 完整画幅、`object-fit: contain`；标签条叠在图外或图下，不挡关键设备。

### 文案语气

- 说明示例：「洁净室 AMHS 物料搬运调度控制台，请使用授权账号登录。」
- 不写「立即开启免费试用」「加入我们」等 SaaS 转化句。

### 标签

- `AMHS` `OHT` `AMR` `STK` `E-Pass` `ERACK`
- 细边框胶囊，主色字，小字号 mono。

---

## 9. 内容页节奏（登录后）

块间距 16px。允许顺序：语义提示 → 页头 → 指标 → 图表 → 列表/辅卡。  
指标装饰渐变预算：同一屏最多一排，且色相须来自设备/状态语义，不得再用模板四色糖果渐变。  
图表用填充编码。

---

## 10. 动效

页面切换可 `fade-slide` 300ms。壳层不做循环光效、视差营销动效。登录页至多一次轻入场（卡或场景淡入）。

---

## 11. 预设

| 预设 | 可变 | 不可变 |
| --- | --- | --- |
| default | 浅色中性 + 青绿主色 + 分栏登录 | 定位与壳槽位 |
| dark | 只换中性色 | 主色、分栏结构、文案语气 |
| compact | 壳尺寸整组缩小 | 主色与登录分栏逻辑 |

---

## 12. 超出标准（一票否决）

- 居中色斑 + 单卡，看起来像通用后台模板或 SaaS
- 主色用紫系 `#646cff` 或大面积紫渐变
- 无厂内语境图、无设备缩写、无双品牌锁
- 主按钮文案写成「立即体验」「免费使用」
- 悬停把字改浅；同一屏两个实心主按钮做同一件事
- 深色玻璃营销风、霓虹描边、大标题衬线展示字体
