# 中后台壳 · 通用标准

> **现行标准已切换：** RCS 厂内产品请以 `rcs-ui-standard.md` 与 `brand-spec.md` 为准（主色青绿、分栏登录、内网语气）。本文仅保留 Soybean 壳层尺寸与历史对照。

这份标准从 Soybean Admin 2.2.0 的默认界面里抽出。它只管「任何一页都必须遵守的规则」，不管某一页上的文案、演示数字和品牌标志。

当前这套默认值只是标准的一组绑定：主色 `#646cff`，浅色，左侧垂直菜单。换预设可以改绑定，不能改规则。

一句话：壳是槽位，主题是一份数据，中性色负责气质，主色只负责识别、选中和主按钮。

## 1. 两层壳，页面不拥有框架

- 空白壳只给独占视口的页面：登录、403、404、500。这些页没有侧栏、顶栏、页签。
- 管理壳给所有业务页。槽位固定为：侧栏、顶栏、页签、内容、页脚。页面只填内容槽。
- 换布局只重排槽位，不重做页面。六种布局（左侧垂直、垂直混合、垂直混合顶栏优先、水平、顶部混合侧栏优先、顶部混合顶栏优先）共用同一套页面。
- 内容区自己滚动。顶栏和页签默认固定。页脚默认不固定，文字靠右。
- 新页面不得自带第二套导航、第二套顶栏或整页营销结构。

## 2. 主题是一份数据

`themeSettings` 是唯一真相。主色、色阶算法、圆角、布局模式、密度、页签形态、页脚、水印、明暗、灰度、色弱都从这一份对象来。页面里不另写一套皮肤。

改主色时，下面这些必须一起变：

- 十一级色阶
- 顶栏进度条
- 组件库的主色、悬停、按下、激活底
- 登录页底色和两块色斑
- 标志旁的产品标题字色
- 菜单选中字、页签活动字、文字链

下面这些不跟主色走，写死在明暗两套中性色里：

- 页面底
- 卡片、顶栏、侧栏、页脚
- 正文
- 反色侧栏（默认关闭）

开发环境不缓存主题，改配置即生效。生产环境才写入本地存储。

## 3. 一种主色，十一级，状态有固定映射

- 全站只有一种主色。它落在色阶 500。
- 默认不用推荐色算法，用 Ant Design 色板。打开推荐色算法会换成另一套气质，不能当作同一套标准的默认。
- 状态映射固定：
  - 默认 = 500
  - Hover = 500（与默认相同，不把字变浅）
  - Pressed = 700
  - 选中底 = 主色 10% 透明
- 信息色默认跟随主色。成功、警告、错误是独立语义色，不从主色推导。信息色只有在关闭跟随时才用自己的蓝色。
- 主色出现的位置只有：主按钮、选中态、活动页签、产品标题、文字链、登录色场。不铺进页面底，不铺进每一张卡片。

当前绑定：主色 `#646cff`。按下 `#3634b3`。选中底 `#646cff1a`。成功 `#52c41a`，警告 `#faad14`，错误 `#f5222d`。信息色不跟随时 `#2080f0`。

## 4. 中性色决定气质，阴影只分层

浅色绑定：

- 页面底 `rgb(247, 250, 252)`
- 卡片、顶栏、侧栏、页脚 `rgb(255, 255, 255)`
- 正文 `rgb(31, 31, 31)`
- 次要说明 `#999`
- 分割和弱文案 `#666`
- 反色侧栏 `rgb(0, 20, 40)`，默认关闭

深色只换中性色，主色不变：

- 卡片 `rgb(28, 28, 28)`
- 页面底 `rgb(18, 18, 18)`
- 正文 `rgb(224, 224, 224)`

阴影只用来把层分开，不制造漂浮：

- 顶栏、页签：`0 1px 2px rgb(0, 21, 41, 0.08)`
- 侧栏：`2px 0 8px 0 rgb(29, 35, 41, 0.05)`
- 内容卡片：`0 1px 2px rgb(0 0 0 / 0.05)`，无描边

灰度、色弱是整页滤镜，默认关闭。圆角分三档：控件 6px，内容卡片 8px，登录卡片 12px。

## 5. 字体和图标不承担个性

- 字体只用系统无衬线栈：`ui-sans-serif, system-ui, Segoe UI, Roboto, Helvetica Neue, Arial, Noto Sans`。
- 不用展示衬线，不用单独的数字字体。
- 字重克制：登录标题 500，产品标题加粗，正文常规。
- 图标是线性图标，来自 Ant Design Outlined、Carbon、MDI。功能位不用表情符号，不用填色插画当图标。

## 6. 壳层尺寸是骨架

默认密度：

| 区域 | 尺寸 |
| --- | --- |
| 顶栏 | 高 56px，左右内边距 12px |
| 页签 | 高 44px |
| 侧栏 | 展开 220px，收起 64px |
| 混合侧栏 | 一级 90 / 收起 64，子菜单 200 |
| 页脚 | 高 48px，右对齐 |
| 内容区内边距 | 16px |
| 卡片间距 | 16px；窄到移动宽度收成 0 |
| 标志 | 侧栏 32px；登录 64px，窄屏 48px |
| 滚动条 | 宽 7px，拇指半透明黑 |

顶栏右侧顺序固定：搜索、全屏、语言、明暗、主题配置、头像。垂直布局下，顶栏左侧是折叠按钮和带图标的面包屑。标志在侧栏顶部，这块高度与顶栏相同，标题 16px、加粗、主色。

菜单垂直，缩进 18px，收起后图标 22px。选中项是主色字加 10% 主色底。

页签是 Chrome 标签。活动项字色为主色，底接近色阶 100。标签之间有细分割线，活动项和悬停时分割线消失。

紧凑预设可以改尺寸，但必须整组改：顶栏 48、页签 36 且改成按钮形态、侧栏 180/48，并隐藏面包屑、搜索、多语言和页脚。不能只改其中一项。

## 7. 控件：一个主动作，状态成对变色

- 同一视图里，同一主动作只有一个实心主按钮。其余入口用次按钮、幽灵按钮或文字链，文案不重复。
- 登录主按钮：通栏、大号、胶囊圆角、主色底、白字。
- 按下把底色换成 700 阶，字保持白色。悬停不把字改成灰色或更接近底色的颜色。
- 禁用是唯一允许降低对比的状态。
- 可聚焦控件有清晰的焦点环。
- 表单大号。登录不显示字段标签，只留占位符。次要操作（记住我、忘记密码）是文字，不是第二个主按钮。
- 触摸热区不小于 44px。窄屏不出现横向滚动，登录内容宽从 400px 收到 300px。

## 8. 内容页的编排节奏

业务页在内容槽里自上而下排列，块与块的间距是 16px。

允许的块类型：

1. 语义提示条。警告用警告色，不用主色。
2. 问候或页头。左是身份和一句说明，右是少量数字。说明字用次要色。
3. 指标行。放在一张白卡片里。中屏两列，大屏四列。单张指标可以是唯一的装饰性彩色块：右下方向渐变、白字、圆角 6px。标题 16px，图标 32px，数字 30px。
4. 图表行。左右比例 14:10。图表用填充编码（面积、环形扇区），不用空心轮廓。数据色独立于主色。
5. 列表加辅卡。同样 14:10。列表标题在左，更多入口是主色文字链。辅卡放一个居中的主视觉，不再叠第二套渐变。

装饰预算：全站只有指标行允许各自不同的渐变色块。图表用数据色。其余卡片保持白底、无描边、轻阴影。

## 9. 登录页：一块色场，一张卡片

- 铺满视口，内容水平垂直居中。
- 底色是白色与主色混合。浅色混合 20%，深色混合 50%。
- 两块色斑在卡片下面，从色阶 200 过渡到 500。一块偏右上，一块偏左下，都大幅移出视口。它们是色场，不是插画。
- 卡片无边框、圆角 12px、表面色盖在色斑上。
- 卡片头：标志、主色产品名、明暗和语言。表单标题 18px、主色。
- 主按钮只有「确认」这一个。其下的模式切换是等宽次按钮。其他账号入口是更小的主色按钮，不和确认按钮抢同一层级。

## 10. 动效只做切换，不做表演

- 默认页面切换是 `fade-slide`：300ms。进入时从左侧 30px 淡入，离开时向右 30px 淡出。
- 另外五种（fade、fade-bottom、fade-scale、zoom-fade、zoom-out）可以配置，默认不用。
- 不在壳层上加持续循环的光效、视差或大面积动画。

## 11. 预设可以换绑定，不能换规则

| 预设 | 允许改的绑定 | 仍然遵守 |
| --- | --- | --- |
| default | 无，就是当前标准 | 全部 |
| dark | 只换中性色 | 主色、槽位、尺寸、状态映射 |
| compact | 整组缩小壳层，并关掉一组顶栏功能 | 色彩规则、控件规则、内容节奏 |
| 换主色 | 色阶、按下色、选中底、登录色场一起重算 | 中性色不跟着染；主色仍只出现在识别位 |

打开推荐色并改成另一支主色，是另一套气质，不拿来当这套标准的默认。

## 12. 违反标准的做法

出现下面任何一条，结果就不再属于这套壳：

- 深色玻璃、网格背景、霓虹描边、大标题衬线
- 主色铺进页面底或每一张白卡片
- 指标行收成同一种渐变，或改成线框图标卡
- 默认把侧栏改成反色
- 页面自带第二套导航、口号区或空状态插画墙
- 用表情符号代替功能图标
- 把业务页做成营销落地页
- 悬停时把文字改浅，或只改前景、不改背景
- 同一视图里放两个以上的实心主按钮做同一件事
